# Webs OSINT

Recopilatorio de webs útiles para reconocimiento, OSINT y búsqueda de información. Ir añadiendo según se vayan usando.

## Forense Estenganografía

- [Aperi Solve](https://www.aperisolve.com/es/) - Plataforma en línea que realiza análisis por capas de imágenes
- [CyberChef](https://toolbox.itsec.tamu.edu/) - Una aplicación web para encriptado, decode, compresión y analisis data.

## Dominios / DNS / Subdominios

- [crt.sh](https://crt.sh/) — certificados SSL emitidos para un dominio (saca subdominios)
- [DNSdumpster](https://dnsdumpster.com/) — mapa de DNS y subdominios
- [SecurityTrails](https://securitytrails.com/) — histórico de DNS, whois, subdominios
- [ViewDNS.info](https://viewdns.info/) — herramientas DNS variadas (reverse IP, whois, etc.)

## IPs / Infraestructura

- [Shodan](https://www.shodan.io/) — buscador de dispositivos e IPs expuestas en internet
- [Censys](https://search.censys.io/) — similar a Shodan, hosts y certificados
- [IPinfo](https://ipinfo.io/) — geolocalización e info de una IP

## Correos / Brechas de datos

- [Have I Been Pwned](https://haveibeenpwned.com/) — comprobar si un correo aparece en brechas
- [DeHashed](https://dehashed.com/) — búsqueda en brechas (de pago)
- [Hunter.io](https://hunter.io/) — buscar correos asociados a un dominio

## Buscadores alternativos

- [Bing](https://www.bing.com/) — dorks tipo `site:` igual que Google
- [DuckDuckGo](https://duckduckgo.com/) — buscador sin tracking, útil para resultados distintos
- [Google Hacking Database (GHDB)](https://www.exploit-db.com/google-hacking-database) — dorks ya preparados

## Archivo / histórico web

- [Wayback Machine](https://web.archive.org/) — versiones antiguas de una web
- [Cachedview](http://cachedview.nl/) — caché de Google de una página

## Redes sociales / personas

- [Sherlock (GitHub)](https://github.com/sherlock-project/sherlock) — busca un usuario en múltiples redes sociales
- [Namechk](https://namechk.com/) — comprobar si un username existe en distintas plataformas
- [Spiderfoot](https://spiderfoot.tools/) - Busqueda de usuarios en múltiples
- []

## Tecnologías web

- [Wappalyzer](https://www.wappalyzer.com/) — detecta tecnologías usadas por una web
- [BuiltWith](https://builtwith.com/) — similar a Wappalyzer, más detallado

## CVEs / Exploits

- [Exploit-DB](https://www.exploit-db.com/) — base de datos de exploits públicos
- [NVD](https://nvd.nist.gov/) — base de datos oficial de CVEs

## Notas

- Ir clasificando por categoría según se añadan más.
- Si una web necesita API key o cuenta, anotarlo junto al enlace.
